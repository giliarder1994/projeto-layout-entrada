# 📬 Projeto Newsletter

## 📌 Sobre o projeto

Este projeto consiste em uma **landing page de inscrição para newsletter**, desenvolvida com foco em **simplicidade, usabilidade e boas práticas de Front-End**. A aplicação simula um formulário de cadastro de usuários para recebimento de novidades por e-mail, oferecendo uma interface limpa e moderna.

A ideia principal foi praticar a criação de formulários, organização de layout e implementação de **tema claro/escuro**, recurso muito comum em aplicações reais.

---

## 🎯 Objetivo do projeto

* Praticar a estruturação semântica com HTML5
* Trabalhar estilização moderna utilizando CSS puro
* Implementar alternância de tema (light/dark) com JavaScript
* Criar um layout responsivo e agradável ao usuário
* Simular um cenário real de página de captura (newsletter)

---

## 🚀 Funcionalidades

* 📝 Formulário de inscrição com campos de nome e e-mail
* 🌗 Alternância entre tema claro e escuro
* 🎨 Uso de variáveis CSS para controle de temas
* 📅 Atualização automática do ano no rodapé
* 📱 Layout simples e responsivo

---

## 🧠 Conceitos aplicados

* Manipulação do DOM com JavaScript
* Eventos de clique
* Uso de atributos HTML (`data-tema`) para controle de estado
* Variáveis CSS (`:root`) para temas dinâmicos
* Organização de código e separação de responsabilidades (HTML, CSS e JS)

---

## 🛠️ Tecnologias utilizadas

* **HTML5** — Estrutura da página
* **CSS3** — Estilização, layout e temas
* **JavaScript (Vanilla JS)** — Interatividade e lógica da aplicação
